# 단어가 말로 이어지는 HSK 1-2급 짝꿍어휘 · 모바일&PC 단어장

《단어가 말로 이어지는 HSK 1-2급 짝꿍어휘》(전진아 지음 · 진담중국어)와 함께 쓰는 단어장 웹앱입니다.
HSK 3.0 필수 단어 500개와 짝꿍표현 1,500개가 책과 같은 번호·같은 쪽(10~109쪽)으로 들어 있어요.

## 이렇게 공부해요
1. **책 펼치기**: 책과 같은 쪽을 열고 ①②③을 톡 눌러 발음을 들으며 소리 내어 읽어요.
2. **내 문장**: 단어를 톡 누르고, 마음에 드는 짝꿍어휘 1~2개로 문장을 써 봐요.
3. **폰 카드**: 아래 **👁 꾹 누르고 떠올리기** 버튼(또는 화면 아무 곳)을 누르고 있으면 병음·뜻이 사라져요. 떠올린 뒤 손을 떼서 확인하고, ⚡ 즉시반응으로 3초 안에 말해 봐요.
4. **다음 날**: '오늘 복습' 탭에서 헷갈린 단어부터 다시 만나요.

기억해 낸 단어는 □□□ 칸을 채워요(첫날 → 1일 뒤 → 3일 뒤). 앱에서 칸이 채워지면 책의 같은 번호에도 칠해 두세요.

## 열기
- 꼭 **크롬**으로 열어 주세요. 카카오톡·인스타그램 등 앱 안에서 링크를 누르면 자동으로 크롬(아이폰은 크롬, 없으면 사파리)으로 넘어가요. 자동으로 안 넘어가면 '크롬으로 열기' 안내 화면이 나와요.
- 카카오톡에 링크를 올리면 `og.png` 미리보기 이미지가 보여요.
- 공부 기록은 이 기기의 이 브라우저(localStorage `jindam-hsk12-book-v1`)에 저장돼요.
- 발음은 Tingting(婷婷) 목소리를 먼저 쓰고, 없는 기기에서는 다른 여자 중국어 목소리로 읽어요.

## 파일
- `index.html`: 앱 전체(화면·데이터·코드 한 파일, 외부 의존 없음)
- `og.png`: 카카오톡·SNS 링크 미리보기 이미지(1200×630)
- `data/hsk12_dapei_words.json`: 단어·짝꿍어휘 원본 데이터 `{n, h, p, k, c:[[한자, 병음, 뜻]×3]}`. 한자 뒤 숫자(예: `一辆3车`)는 3급 이상 표시예요.
